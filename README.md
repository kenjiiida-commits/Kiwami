# 極み窓（Kiwami）

小さな窓にファイルをドロップするだけで、中身の本当の種類を見分けたり、
各種操作をしたりできる Ubuntu 用ソフトです。

Windows 用のフリーソフト「極窓」（NTSOFT）の使い心地を目標にした、
別の作者による新しいソフトです。元の極窓とは関係ありません。

作者: 飯田顕治 ／ ライセンス: MIT

## 現在の段階（Ver.0.1.0 ／ 第1段階）

- 小窓にファイル・フォルダーをドラッグ＆ドロップ（「開く…」ボタンや Ctrl+O でも可）
- 中身から判別した種類・MIME・本来の拡張子を表示
- 今付いている拡張子と並べて表示
- 「常に最前面」の切り替え（設定と窓の位置は次回も引き継ぎ）

## 必要なもの

Ubuntu 24.04 以降を想定しています。

```bash
sudo apt install python3-pyside6.qtwidgets libmagic1
```

## 起動

```bash
cd ~/development/kiwami
python3 -m kiwami
```

ファイルを指定して起動することもできます。

```bash
python3 -m kiwami ~/ダウンロード/何かのファイル
```

## テスト

```bash
python3 -m unittest -v
```
