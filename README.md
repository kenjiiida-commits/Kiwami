# 極み窓（Kiwami）

小さな窓にファイルをドロップするだけで、中身の本当の種類を見分けたり、
各種操作をしたりできる Ubuntu 用ソフトです。

Windows 用のフリーソフト「極窓」（NTSOFT）の使い心地を目標にした、
別の作者による新しいソフトです。元の極窓とは関係ありません。

作者: 飯田顕治 ／ ライセンス: MIT

## できること（Ver.0.6.0 ／ 第6段階まで）

- 小窓にファイル・フォルダーをドラッグ＆ドロップ（「開く…」ボタンや Ctrl+O でも可）
- 中身から判別した種類を日本語で表示（MIME・詳しい説明も）
- 今の拡張子が中身と合っているかを色付きの帯で表示
  - 緑：合っている ／ 赤：違う ／ 黄：拡張子がない ／ 灰：判定できない・確実ではない
- 違っていれば、ボタン1つで正しい拡張子に直せる（同じ名前のファイルがあるときは上書きしない）
- 名前の変更（F2）、属性（パーミッション）の変更、更新日時・アクセス日時の変更
  - ボタンのほか、一覧の右クリックメニューからも使える
- 「元に戻す」（Ctrl+Z）で、名前・拡張子・属性・日時の変更を新しい順に取り消せる
  - 取り消す前に、別のファイルに入れ替わっていないか・さらに書き換えられていないかを確かめる
  - 取り消しの記録は、ソフトを閉じると消える
- 「中身を見る」（ダブルクリックでも可）で、別の窓に中身を表示
  - テキスト：文字コードを自動判別（UTF-8・Shift_JIS・EUC-JP・JIS・UTF-16）。外れたら手で切り替え。改行の種類と行数も表示
  - 画像：窓に合わせて縮小表示、アニメーション GIF も再生、スマホ写真の向きも補正
  - 16進：大きなファイルでも少しずつ読むので軽い。アドレスを指定して移動できる
  - 圧縮ファイルの中身一覧：zip・tar・tar.gz などに加え、7z・rar・lzh も（7z コマンドを使用）。Windows で作った zip の日本語名も文字化けしない
- 解凍：圧縮ファイルと同じ場所に新しいフォルダーを作り、その中へ出す
  - zip・7z・tar.gz・tar.xz・tar.bz2・rar・lzh・cab・iso など
  - 同じ名前のフォルダーがあれば「名前 (2)」にする（上書きしない）
  - パスワード付きなら入力欄を出す
  - 「../」などで外の場所へ書き出そうとする項目や、危ないリンクは書き出さない
  - 途中で中止・失敗したら、作りかけのフォルダーは消す
  - Python で読めない zip（4GB を超えるものの一部や Deflate64 など）は、自動で 7z に切り替えて解凍する
  - 一部が壊れた圧縮ファイルでも、無事なファイルはすべて取り出し、壊れていたファイルの名前を知らせる
    （tar.gz などは壊れた所より後ろは取り出せない。どのファイルか特定できない場合もそう知らせる）
- 圧縮：一覧で選んだもの（Ctrl・Shift で複数可）を zip・7z・tar.gz・tar.xz にまとめる
  - zip・7z はパスワードを付けられる（zip は AES-256 か ZipCrypto、7z はファイル名も隠せる）
  - 同じ名前のファイルがあれば番号を付ける。中止・失敗したら作りかけは消す
- 「常に最前面」の切り替え（設定と窓の位置は次回も引き継ぎ）
- まとめて処理：一覧で複数選ぶ（Ctrl・Shift）と、属性・日時をまとめて変更できる
  - 「拡張子をまとめて直す」：食い違い・拡張子なしのものを、変更前後の一覧で確かめてから一度に直す
  - まとめて行った変更は、「元に戻す」1回でまとめて戻る
- フォルダーを右クリック →「フォルダーの中身を一覧に入れる」（サブフォルダーの中も。最大 20,000 個）
- 履歴：最近扱ったファイルを「履歴…」から一覧に呼び戻せる（消す・残さない設定もできる）
- 極み窓が開いているときに別のファイルを渡すと、新しい窓は開かず、開いている窓に追加する

## 自分用の辞書

「辞書…」ボタンを押すと `~/.config/kiwami/types.json` が開きます（初回はひな形を作ります）。
ここに項目を書くと、形式を追加したり、日本語の名前を変えたりできます。
保存すると、次にファイルをドロップしたときから反映されます。

```json
{
  "types": [
    {
      "mime": ["application/x-jikkyo-data"],
      "name": "自作ソフトのデータ",
      "exts": ["jkd"],
      "signature": {"offset": 0, "hex": "4A4B4430"}
    }
  ]
}
```

| 項目 | 意味 |
| --- | --- |
| `mime` | 判別エンジンが返す MIME（複数可）。組み込み辞書と同じ MIME なら自分用が優先 |
| `name` | 表示する日本語の名前 |
| `exts` | 正しい拡張子（先頭が「直す」ときのおすすめ） |
| `also` | 付いていても警告しない拡張子（その形式を土台にした別形式など） |
| `text` | `true` ならテキスト系（拡張子は自由） |
| `noext_ok` | `true` なら拡張子なしが普通の形式 |
| `weak` | `true` なら判別が外れやすい形式（違っていても赤い警告にしない） |
| `signature` | 先頭からの位置（`offset`）と16進のバイト列（`hex`）。自分用辞書のものは判別エンジンより優先 |

組み込み辞書は `kiwami/data/types.json` にあります。

## 必要なもの

Ubuntu 24.04 以降を想定しています。

```bash
sudo apt install python3-pyside6.qtwidgets python3-pyside6.qtnetwork libmagic1
```

`python3-pyside6.qtnetwork` は「窓を1つにまとめる」機能に使います（なくても動きます）。

あると便利なもの（なくても動きます）:

```bash
sudo apt install 7zip unrar qt6-image-formats-plugins
```

- `7zip`：7z・lzh などの中身一覧と解凍、7z の作成、パスワード付き zip の作成に使います
- `unrar`：rar の解凍に使います（Ubuntu の 7zip には rar を展開する部品が入っていないため）
- `qt6-image-formats-plugins`：WebP・TIFF などの画像を表示できるようになります

## DEB パッケージで入れる（おすすめ）

対象は Ubuntu 25.04 以降です（Ubuntu 公式の PySide6 パッケージを使うため）。
GitHub のリリースから `kiwami_<版>_all.deb` を取ってきて、次のように入れます。

```bash
sudo apt install ./kiwami_0.6.0_all.deb
```

- 必要なもの（PySide6・libmagic）は自動で入ります。7zip なども、おすすめとして一緒に入ります
- rar を解凍するときは `sudo apt install unrar` も入れてください
- アプリ一覧に「極み窓」が出ます。端末からは `kiwami` で起動できます
- ファイル画面の右クリックに出したいときは、極み窓の「その他」→「ファイル画面の右クリックに登録する」
- 外すときは `sudo apt remove kiwami`

自分で DEB を作るときは `bash packaging/build-deb.sh`（`dist/` にできます）。

## ソースのまま、アプリ一覧・右クリックに登録する

```bash
cd ~/development/kiwami
bash install.sh
```

- アプリ一覧に「極み窓」が出ます
- ファイル画面（Nautilus）でファイルを右クリック →「スクリプト」→「極み窓で調べる」
- 外すときは `bash uninstall.sh`
- DEB で入れる場合は、先に `bash uninstall.sh` で外してください（アプリ一覧に2つ並ぶのを防ぐため）

## 起動

```bash
cd ~/development/kiwami
python3 -m kiwami
```

ファイルを指定して起動することもできます。

```bash
python3 -m kiwami ~/ダウンロード/何かのファイル
```

## 注意

- zip のパスワードには半角の英数字と記号だけが使えます（zip の仕組みの都合）。7z は日本語も使えます。
- パスワード付きの圧縮・解凍では、7z や unrar にパスワードを渡して動かします。動いている数秒の間、
  同じパソコンの他のユーザーからコマンドの内容として見える可能性があります。
